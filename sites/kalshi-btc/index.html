EXIT LOGIC FLOW

① Take-Profit (full 540s window)
• Net sell > entry price (profitable after fees)
• Net sell > model EV + edge (relaxes near expiry)
② Stop-Loss (last 300s only)
• Unrealized loss > stop threshold (tightens near expiry)
• Model gate: SL only fires if model confirms flip
Holding YES → fires only if p_fair < 0.35
Holding NO → fires only if p_fair > 0.65
• Model disagrees → SL_PRICE_HIT_MODEL_HOLD
